# Active Impersonation Review

This directory is reserved for review-oriented reports generated by `scripts/generate_active_impersonation.py`.

It is intentionally separate from the standard `hardening/` blocklists:

- `hardening/lists/` contains exact-host lookalike blocklists from DNSTwist
- `hardening/active_impersonation/` contains scored review artifacts for live lookalikes that resemble the real brand

When the report stage runs, this directory will be updated with:

- `report.json` - machine-readable full results
- `results.tsv` - spreadsheet-friendly flat export
- `README.md` - Markdown summary of the latest run

Recommended use:

1. Run `scripts/generate_twisted.py` first
2. Run `scripts/generate_active_impersonation.py` against all or selected targets
3. Review `HIGH_MATCH` and `MEDIUM_MATCH` rows before promoting anything into a curated blocklist

The scheduled hardening workflow can generate these reports too, but it is off by default because probing every live lookalike site is materially heavier than generating the DNSTwist blocklists alone.
