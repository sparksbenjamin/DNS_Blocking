# Active Impersonation Review

This directory is reserved for review-oriented reports generated by `scripts/generate_active_impersonation.py`.

Quick links:

- [Back to Hardening](../README.md)
- [Back to Repo Root](../../README.md)

It is intentionally separate from the standard `hardening/` blocklists:

- `hardening/lists/` contains exact-host lookalike blocklists from DNSTwist
- `hardening/active_impersonation/` contains scored review artifacts for live lookalikes that resemble the real brand

When the report stage runs, this directory will be updated with:

- `report.json` - machine-readable full results
- `results.tsv` - spreadsheet-friendly flat export
- `README.md` - Markdown summary of the latest run

Recommended use:

1. Run `scripts/generate_twisted.py` first
2. Run `scripts/generate_active_impersonation.py` against all or selected targets
3. Review `HIGH_MATCH` and `MEDIUM_MATCH` rows before promoting anything into a curated blocklist

The recommended automation path is the separate `Update Active Impersonation Review` workflow, which can run on its own cadence without re-running DNSTwist.

If you only see this placeholder after a review workflow run, the most likely reason is that the workflow has not completed yet or has not committed a generated report.

Useful repo variables for the review workflow:

- `ACTIVE_IMPERSONATION_RUNNER_LABELS=["self-hosted","linux"]`
- `ACTIVE_IMPERSONATION_READ_TIMEOUT=10`
- `ACTIVE_IMPERSONATION_CONNECT_TIMEOUT=5`

Optional scope controls:

- `ACTIVE_IMPERSONATION_TARGETS=paypal,microsoft,okta`
- `ACTIVE_IMPERSONATION_MAX_CANDIDATES=25`

When the stage runs successfully, this directory will contain a generated summary README plus:

- `report.json`
- `results.tsv`
